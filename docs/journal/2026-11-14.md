## 결정

### 기아 한시 조치를 예정대로 되돌렸다 (1h → 6h)

10-31에 2주 한시로 내렸던 것이다. **되돌리기 기준을 미리 적어두고 그 기준으로 판정했다.**

```
기준:  `기아` 검색 100건 중 야구 비율 20% 미만이면 시즌 종료
실측:  야구 1%          (10-31 당시 84%)
       유입 11.5건/시간  →  6h 주기에 104건 / 1000  (여유 10배)
```

제목 표본도 전부 자동차·증시 기사다 — `쏘카 현대차 자율주행`, `폭스바겐 ID.5`,
`주간 거래소 외국인`. 10-29의 `유재석 결혼식`·`벼랑 끝 LG 불펜데이`와 대비된다.

### 조치는 효과가 있었다 — 2주를 완주했다

```
10-17  gap 발생
10-18  gap 발생
10-29  gap 발생
10-30  gap 발생
10-31  ← 주기 6h → 1h
  ...  한국시리즈 전 구간
11-14  gap 추가 0건
```

**마지막 손실이 조치 하루 전이다.** 그 뒤 2주 동안 0건이다. 되돌린 뒤 강제 수집으로
확인하니 6h 주기에서도 1페이지로 경계에 닿는다.

### 되돌리기를 기억에 맡기지 않은 것이 통했다

`config/universe.json`의 `_temp_until`·`_temp_revert_to`·`_temp_reason`, `changelog`,
핸드오프의 ★ 항목 — 세 군데에 날짜와 복귀값을 박아뒀다. **판정 기준까지 같이 적은
것이 핵심이었다.** "시즌이 끝나면"이라고만 적었으면 오늘 다시 재고 고민했을 것이다.

마커는 전부 제거했고 `changelog`에 되돌림 기록을 남겼다.
