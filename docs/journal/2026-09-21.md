## 결정

### 1. 측정 대상을 다시 못박았다 — **AI 퀀트 시스템**

09-18 일지에 "로보어드바이저를 만든다면 코스콤 테스트베드 분포가 최종 비교군"이라고
적었다. **정정한다.**

사용자 지적: *"자산배분이라는 분야는, 사용자의 재무상태나 위험수준에 의해 결정되는
분야라고 본다. 내가 만들고자 하는 것은 mas를 통해서 ai 퀀트 시스템에 더 가깝다."*

맞다. 이 구분이 검증 방법 **전체**를 바꾼다.

| | 자산배분 / 로보어드바이저 | **AI 퀀트 (이 프로젝트)** |
|---|---|---|
| 푸는 문제 | 적합성 — 이 고객에게 맞는가 | **알파** — 시장을 이기는 신호가 있는가 |
| 정답을 정하는 것 | 고객의 재무상태·위험성향 | 실현 수익률 |
| 표준 지표 | 위험등급별 적합성·분산 | **IC / ICIR** |

→ **코스콤 테스트베드 비교군 철회.** 그쪽 심사 항목은 "투자자 성향 반영·분산투자
구조"라서 평가 축이 다르다. 09-18 결정 4번을 이걸로 대체한다.

이 정정이 값졌던 이유: 측정 대상이 바뀌자 **"표본이 부족하다"는 진단 자체가 바뀌었다.**
로보어드바이저로 보면 부족한 건 시간(레짐)이다. 퀀트로 보면 부족한 건 **폭(종목 수)**이고,
그건 지금 당장 늘릴 수 있다.

### 2. 주 지표는 IC / ICIR

기획서 9.1절이 "가장 중요한 지표"로 꼽아둔 **확신도-수익 상관이 사실상 IC였다.**
이름을 몰랐을 뿐 이미 재고 있었다. 퀀트 표준 정의로 통일한다.

룰 베이스라인 3년 실측 (20거래일):

```
KR  momentum_60d   IC +0.035   t=+1.09    ICIR +0.74
KR  reversal_5d    IC -0.049   t=-1.52    ICIR -1.03
US  momentum_60d   IC -0.094   t=-2.80    ICIR -1.90
US  reversal_5d    IC +0.094   t=+3.13    ICIR +2.13   <- 실전급
```

업계 통념(2026-09-21 확인): **IC 0.02~0.05면 쓸 만한 팩터, 0.10이면 매우 강함.**

### 3. 병목은 기간이 아니라 **유니버스 크기**다

한 시점 IC의 표준오차 = `1/√(N-1)`.

| 종목 수 N | 1회 IC 오차 | IC=0.05 검출에 필요한 시점 수 |
|---|---|---|
| **15 (현재)** | **0.267** | 114회 — 주1회 **2.2년** |
| 60 | 0.130 | 27회 — 0.5년 |
| 300 | 0.058 | **5회 — 0.1년** |

15종목이면 잡음 ±0.267에 신호 0.05다. **신호 대 잡음비 1:5.** KR 모멘텀이 IC +0.035인데도
t=1.09로 안 잡히는 건 실력이 없어서가 아니라 자가 굵어서다.

```
시간 늘리기  →  √T 로만 개선
종목 늘리기  →  √N 로 개선되고, 시간과 곱해진다
```

> **3개월 × 300종목 > 2.2년 × 15종목.**

기획서 14.1절(전체 시장 확장)을 "3개월 이후"에서 **1순위로 앞당긴다.**

선행 조건이던 **생존 편향은 전진 검증에서 발생하지 않는다** — 오늘 상장된 종목으로
오늘부터 쌓기 때문이다. 09-18에 "유니버스 15종목을 2026년에 골라 2024년 백테스트에
쓰는 것 자체가 편향"이라고 적었는데, 그건 **과거 백테스트를 할 때만** 성립하는 문제였다.
과거 백테스트를 접으면 같이 사라진다.

남은 선행 조건은 하나다: **전 종목 점수 저장** (`validation.md` 3.3).
상위 N개만 시그널을 내면 고른 것만 채점돼서 *"고른 것과 안 고른 것의 차이"*를 모른다.
그게 스크리너의 실제 성능이고 IC 계산에 필요한 값이다.

### 4. 실험 순서를 고정했다

```
1  노이즈 바닥 측정   (선행 필수 · 하루 · 약 $2)
2  유니버스 확대
3  다중 아암 + 부분요인 설계
4  전진 마스킹        (음성 대조군)
```

1번이 먼저인 이유: `temperature=0`이어도 결정론이 아니다. 같은 구성을 반복 실행해
`Var(A−B)`의 순수 잡음을 먼저 알아야 "A가 B보다 낫다"가 실재인지 판정된다.
**이걸 안 하고 A/B를 돌리면 잡음을 실력으로 읽는다.** 기획서 6절의 "3회 이상 반복해
평균이 아니라 분산까지 본다"가 이것이다.

3번에서 **조합 1,116가지가 LLM 호출 0회로 탐색된다** (에이전트 부분집합 31 × 호라이즌 3 ×
보유 규칙 2 × 확신도 임계 3 × 비중 방식 2). 전량 로깅이 여기서 값을 낸다.
새 호출이 필요한 차원만 부분요인 설계로 압축한다 — 4요인 2수준이면 완전요인 16조합을
**8아암**으로 주효과 전부 추정. 다중검정 대가는 인정한다(8아암 Bonferroni `|t| > 2.73`).
**개별 아암 순위가 아니라 요인의 주효과를 본다.**

## 문제와 원인 — 검토 과정에서 내가 틀린 것들

일지 규칙대로 지우지 않고 남긴다. 다섯 개다.

### A. 횡단면 15종목을 독립 표본으로 셌다

- **증상**: 표본 수를 계산하면서 종목 수 × 시점 수를 그냥 곱했다.
- **모순**: 나 자신이 앞서 날짜로 그룹지어 분석해놓고, 표본 계산에서는 그걸 잊었다.
- **실측**: 종목쌍 잔차수익 평균상관 **KR ρ=+0.133 → 유효 표본 5.2 / US ρ=−0.036 → 30.1**.
  같은 날 15종목은 같은 시장을 타므로 15개가 아니다.
- **원인**: 편의한 방향의 계산을 검산 없이 썼다.

### B. 목표 상관계수를 업계 기준의 5~10배로 잡았다

- **증상**: "ρ=0.2~0.3을 잡으려면 표본이 N건 필요하다"로 설계를 짰다.
- **확인**: 퀀트 통념은 IC 0.02~0.05가 쓸 만한 수준, 0.10이 매우 강함.
- **원인**: 팩터 업계 기준을 모른 채 일반 통계 감각으로 목표를 세웠다.
- **파장**: 목표를 10배 높게 잡으니 **"어떤 설계로도 표본이 부족하다"**는 결론이 나왔고,
  그 결론이 "과거 데이터를 사자"는 방향으로 끌고 갔다. 틀린 목표가 틀린 전략을 낳았다.

### C. 기간을 줄여 반복 횟수를 늘리자고 제안했다

- 사용자 반박: *"기간을 줄이면 정확도와 신뢰성은 같이 내려간다. 다시한번 생각해봐라."*
- **맞다.** 시간축에서 표본을 짜내려는 시도는 전부 정밀도를 깎는다.
  출구는 시간축이 아니라 **횡단면**이었다 (결정 3).

### D. 1거래일 호라이즌으로 표본 5배 — 실측으로 자기 기각

- "호라이즌을 시그널 간격에 맞추면 겹치지 않는다"는 것 **자체는 맞다** (주1회 + 20거래일은
  4배 겹친다). 독립 관측이 113 → 564로 는다.
- 그러나 실측: **1일 vs 20일 전략 순위상관 KR +0.60 / US +0.30.**
  `US ma_gap_120d`는 1일 2위 → 20일 5위(꼴찌).
- **결론**: 호라이즌은 자유 파라미터가 아니다. 1일에서 이긴 구성이 20일에서 이긴다는
  보장이 없다. 표본을 늘린 게 아니라 **다른 문제를 푼 것**이다.

### E. "과거 뉴스와 결과가 강하게 연결돼 있다"는 부정확한 서술

- 사용자 반박: *"과거 뉴스를 한번에 입력하는 게 아니라 시간 순서대로 입력할 것이다.
  과거 1년의 첫 주 → 리밸런싱 → 이후 일주일 검증 → 리밸런싱으로 나아가는데,
  왜 과거 뉴스와 결과가 강하게 연결되어 있다는 거지?"*
- **정당한 지적이었다.** 두 가지를 뭉뚱그려 말했다.

| | 정체 | 워크포워드로 해결되나 |
|---|---|---|
| **데이터 룩어헤드** | 미래 데이터가 입력에 섞임 | **완전히 해결된다** |
| **학습 룩어헤드** | 모델 가중치가 이미 그 구간을 봤음 | **구조로 해결 불가** |

  사용자가 말한 순차 투입은 첫 번째를 완전히 없앤다. 내가 지적하려던 건 두 번째인데
  구분해서 말하지 않았다.
- **가설과 사실의 구분도 놓쳤다**: "뉴스가 지표보다 강한 회상 단서"라는 것은
  **가설이지 측정이 아니다.** 측정된 건 마스킹 가능성뿐이다 — 1차 자료 4,000건 중
  회사명 포함 83.6%(치환 가능), 명시적 시점 표지 23.1%(제거 가능), 그러나 사건 자체
  (`버라이즌·6G·ISAC`)가 시점을 특정하므로 지울 수 없다.

### F. 자산배분 트랙으로 우회하자고 제안했다

- **근거는 진짜였다**: 자산군 ETF는 21~34년 이력이 있고 매크로·FOMC까지 전부 무료라,
  과거 백테스트가 실제로 가능하다. "구조를 먼저 검증하자"는 논리로 제안했다.
- **기각 사유**: 문제 종류가 다르다 (결정 1). *"자산배분에서 작동한 구조가 종목 선택에서도
  작동한다"*는 전이 가정에 근거가 없다.
- **남는 것**: 매크로·FOMC 데이터가 전부 무료라는 사실은 유효하다. 거시 에이전트를 붙일 때 쓴다.

### 뉴스 — 빅카인즈는 유료 확정, 판매처가 옮겨갔다

본문 200자까지는 빅카인즈, 그 이상은 **뉴스토어**(언론진흥재단).

```
분석용 뉴스데이터 (본문 200자)   비영리 12,397~17,710원/월   ★ 인공지능 활용 목적 불가
분석용 (Full text)              비영리 53,900~77,000원/월    ★ 동일
AI·상업 허용 뉴스데이터           1개 매체 330만원/월 ~ 51개 이상 990만원/월
```

**우리 용도가 정확히 "AI 활용"이라 싼 상품은 약관상 못 쓴다.** 쓸 수 있는 건 최소 구성도
월 330만 원. 같은 돈이면 전진 실험을 수십 아암으로 1년 내내 돌린다.

사용자 질문: *"빅카인즈 유료버전을 붙이면 과거 1년을 돌리는 이점이 더 클까?"*
→ **아니다. 샀어도 1년으로는 절대 성능 검증이 안 된다** (실측):

| | |
|---|---|
| 검정력 | 20거래일 유효 표본 KR 37건 · US 107건 — 주 지표가 미달 |
| 학습 룩어헤드 | 대리기준(2026-04-24) 이후 깨끗한 구간이 38%뿐. 그것만 쓰면 KR 5일도 57건 |
| **레짐** | **1년에 2종뿐. KR 하락 8회, US 하락 0회** — 하락장 검증 불가 |
| 입력 불일치 | 뉴스토어는 매체 기반 아카이브라 네이버 키워드 검색과 선별 방식이 다르다 |

상대 비교(A vs B)에는 유효하다. 절대 성능 검증에는 못 쓴다.

  방향 없는 스크리닝 점수를 전 종목에 저장해야 IC를 계산할 수 있다 (`validation.md` 3.3)
