## 확인한 것

### 네이버 검색 API는 `-` 제외 연산자를 지원하지 않는다 — **반대로 동작한다**

```
'기아'                      야구  76%   total 1,950,177
'기아 -타이거즈'               야구 100%   total    57,116
'기아 -타이거즈 -프로야구 -KBO'   야구 100%   total     9,840
'기아 +자동차'                야구   2%   total   421,232
```

`-타이거즈`가 제외가 아니라 **포함에 가깝게** 처리된다. 그대로 넣었으면 100% 야구
기사를 기아 뉴스로 저장하면서, 제외 규칙이 뒤에서 다 버려 **회사 기사 0건이 되는데도
조용히 돌았을 것이다.** `+`(AND)는 정상 작동한다.

**다음에 누가 또 `-`를 시도하기 전에 이 줄을 읽기를.**

### `+`로 좁히면 재현율을 잃는다

저장된 기아 1차자료 1,165건(10-01 이후, 야구 제외)에 조건을 걸어본 결과다.

| 조건 | 남는 비율 |
|---|---|
| `+자동차` | 47.2% |
| `+현대차` | 53.7% |
| `+전기차` | 11.3% |

**이건 하한이다** — 네이버는 본문까지 검색하는데 우리는 제목·요약만 저장한다
(본문 크롤링 금지). 실제 재현율은 더 높겠지만 **얼마나 높은지 잴 방법이 없다.**

### 다른 종목은 안전하다 (10-25 실측, 포스트시즌 기간)

| 검색어 | 야구 | | 브랜드만 검색 | 야구 |
|---|---|---|---|---|
| 삼성전자 · 삼성바이오로직스 | **0%** | | 삼성 | 22% |
| LG에너지솔루션 · LG화학 | **0%** | | LG | 35% |
| 한화에어로스페이스 | 1% | | 한화 | 15% |
| **기아** | **20%** | | 기아 | 20% |

복합명은 야구 기사에 그 문자열이 안 나온다. **KT는 유니버스에 없다.**
→ 삼성·LG·한화에 제외어를 추가할 이유가 없다. 넣으면 이득 0에 `-` 부작용만 남는다.

## 틀린 판단 — 정정

10-19에 **"LG화학이 24h 주기에 857건 필요, 여유 17%라 위험하다"**고 적고 주기 단축을
제안했다. **그 측정 자체가 버스트였다.**

```
            10-19          10-25        변동폭
기아        35.7건/시간    10.2건/시간    3.5배
LG화학      23.8건/시간     1.1건/시간     22배
기아(버스트) 147건/시간                   14배
```

`measure_news_rate.py`가 한 시점 측정이라 버스트를 못 잡는다고 지적해놓고,
**내 제안도 똑같이 한 시점 측정에 기대고 있었다.** 적용했으면 평상시 40건짜리
종목을 4배 더 긁고 있었을 것이다. 제안을 철회한다.

진짜 결론은 이것이다 — **유입 속도가 종목·시점에 따라 20~100배로 흔들린다.
어떤 고정 주기도 버스트에서 뚫리고, 버스트에 맞추면 평상시에 과잉이다.**

## 미결

- **포스트시즌이 재개되면 기아는 다시 뚫린다.** 10-25 현재 20%까지 내려왔지만
  경기가 있는 날 다시 오른다. 손실이 나면 또 영구 손실이다
- **적응형 주기가 구조적 해답이다.** 수집기는 상한에 걸린 순간을 이미 안다
  (`reached_floor=0`, `페이지 상한:` 알림). 그 신호로 해당 종목 주기를 일시 단축하면
  기아 케이스가 자가 치유된다. 호출 여유도 충분하다 (하루 600회 / 한도 25,000)
- **영구 손실 gap이 안 닫혀 심각이 계속 울린다.** 커버리지 미달은 설계상 자동으로
  닫히지 않는데, 그래서 **이미 아는 손실 2건 때문에 10-17부터 매일 심각이다.**
  09-28에 "매일 울리는 심각은 아무도 안 본다"고 적은 그 상태다 —
  `새로 난 손실`과 `이미 아는 손실`을 가르는 장치가 없다
- 이번엔 셋 다 고치지 않고 기록만 남긴다
