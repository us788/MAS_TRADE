# 2026-10-31

## 문제와 원인

### 기아가 예고대로 재발했다 — 손실이 더 크다

10-25에 "포스트시즌이 재개되면 다시 뚫린다"고 적고 기록만 남겼다. 엿새 만에 두 건이
더 났다. 한국시리즈 기간이다.

```
10-17  빈 구간  +97분   1,000건 중 회사 기사  222건
10-18  빈 구간  +24분                        173건
10-29  빈 구간 +242분                         38건   ← 타이거즈 90%
10-30  빈 구간 +187분                        149건   ← 타이거즈 84%
                누적 550분 = 9.2시간 영구 손실
```

10-29는 1,000건 중 **38건**만 회사 기사였다. 96%가 야구다.

- **기록만 남긴 대가가 측정됐다.** 엿새에 429분이 추가로 날아갔다.
- 네 건 모두 새 판정 기준(직전 성공 수집 시각)으로 양수다 — **전부 진짜 손실이다.**

## 결정

### 기아 수집 주기를 6h → 1h로, **2주 한시**

| 기각한 대안 | 사유 |
|---|---|
| `-타이거즈` 등 제외어 | **네이버는 `-`를 제외가 아니라 포함처럼 처리한다**(10-25 실측: 야구 76% → 100%) |
| `기아 +자동차`로 좁히기 | 재현율을 최소 절반 잃는다. 본문 크롤링을 안 하므로 실제 손실폭을 **잴 수 없다** |
| 적응형 주기 (구조적 해답) | 맞지만 지금 구현할 시간이 없다. 시즌은 2주 뒤 끝난다 |
| 그대로 두기 | 엿새에 429분이 날아가는 속도다 |

1h가 **하한이다** — 수집 작업 자체가 매시 발화하므로 그 아래는 의미가 없다.
피크(476건/시간)에 lookback 1.5h면 714건이라 1,000건 안에 들어온다.

### 되돌리는 것을 기억에 맡기지 않는다

`src/data/universe.py`가 **아는 키만 `row.get`으로 읽으므로** 모르는 키는 무시된다.
그래서 되돌릴 날짜와 값을 **바꾸는 파일 안에** 박았다.

```json
"collect_every_hours": 1,
"_temp_until": "2026-11-14",
"_temp_revert_to": 6,
"_temp_reason": "KBO 포스트시즌 한시 조치 ..."
```

`changelog`에도 남겼다(파일의 기존 규약).

## 해결 — 즉시 효과가 확인됐다

같은 종목, 5분 간격, 주기만 다르다.

```
15:05  (6h)  10페이지 149건  reached_floor=0  →  gap 기록
15:10  (1h)   1페이지  17건  reached_floor=1  →  정상
```

직전 회차가 10페이지를 다 쓰고 실패한 자리에서 다음 회차는 1페이지로 끝났다.
지금 오염도가 84%인데도 1페이지면 충분하다 — **여유 10배다.**

## 그 밖에 — 10-28 베이스라인이 25/30으로 깨졌다

```
US 2026-10-28  15/15
KR 2026-10-28  10/15   실패: 000660 · 373220 외 APITimeoutError
```

10-14(29/30)에 이어 두 번째다. 미결 "부분 성공이 완료로 기록된다" 그대로 —
가드가 `succeeded > 0`을 완료로 보므로 **5건은 재시도 없이 영구 손실**이다.
10-21은 30/30이었으니 3회 중 2회가 부분 실패다. **빈도가 올라가고 있다.**

## 지표

```
KR  5거래일  87/97  0.388[0.26,0.53]   비용후 -1.16%[-3.42,+1.75]%p   확신도상관 -0.093(n=49)
US  5거래일  85/100 0.457[0.32,0.60]   비용후 -0.32%[-1.51,+1.27]%p   확신도상관 +0.005(n=46)
KR 20거래일  43/97  0.556[0.34,0.75]   비용후 +3.78%[-2.25,+10.48]%p  확신도상관 +0.031(n=18)
US 20거래일  40/100 0.583[0.39,0.76]   비용후 +2.12%[-1.10,+5.73]%p   확신도상관 -0.432(n=24)
```

**20거래일이 양쪽 다 양수로 돌아섰다.** 네 구간 모두 0.5(와 0)를 품으므로 아직
동전과 구분되지 않는다. 해석하지 않는다.

**US 20일 확신도 상관 -0.432(n=24)만 따로 적어둔다.** 그 표본 크기의 잡음대(±0.267)를
처음으로 벗어났고 명목상 5% 수준이다. 다만 **부호가 반대다** — 확신도가 높을수록
성적이 나쁘다. 그리고 이런 상관을 지금까지 여덟 번쯤 들여다봤으므로 다중검정을
감안하면 아직 주장할 수 없다. **다음 회차에서 부호가 유지되는지가 관전 포인트다.**

## 미결

- **2026-11-14에 기아 주기를 6h로 되돌린다.** `_temp_until`·`_temp_revert_to` 참고.
  되돌리기 전에 오염도를 다시 재서 시즌이 실제로 끝났는지 확인한다
- **적응형 주기는 여전히 미구현이다.** 이번 조치는 2주짜리 반창고다. 내년 포스트시즌에
  같은 일이 반복되고, 실적 시즌 같은 다른 버스트에는 아무 대비가 없다
- **영구 손실 gap이 안 닫혀 심각이 계속 울린다.** 이제 4건이다. 10-17부터 보름째
  같은 이유로 심각이고, 이번처럼 **진짜 새 손실이 섞여도 구분되지 않는다** —
  실제로 2건에서 4건으로 는 것을 알아채는 데 엿새가 걸렸다
- **베이스라인 부분 실패 빈도가 올라간다** (10-14 29/30, 10-28 25/30)
