# 2026-09-14

## 결정

**LLM은 DeepSeek로 확정.** 라인업은 `deepseek-flash` / `deepseek-v4-pro`, 둘 다 1M 컨텍스트에
thinking / non-thinking 모드를 지원하고 OpenAI ChatCompletions와 호환된다.
단가는 확인일 기준이며 구조(2단 모델·캐시·오프피크)를 규칙으로 삼는다.

여기서 파생된 결정 셋:

- **베이스라인을 DeepSeek 단일 호출로 통일.** "범용 LLM 단독 판단" 벤치마크에 다른 벤더
  모델을 두면 "구조가 이겼나"와 "모델이 더 좋았나"가 분리되지 않는다. 모델을 고정해야
  멀티에이전트 구조만이 변수가 된다.
- **오프피크 배치.** 피크는 UTC 월~금 01:00–04:00·06:00–10:00 = KST 10\~13시, 15\~19시.
  그 외 반값이라 주간 시그널 생성은 KST 심야에 돌린다.
- **프리픽스 캐싱을 설계 규칙으로.** 캐시 히트가 미스보다 모델에 따라 30~50배 싸다.
  시스템 프롬프트·스키마를 바이트 단위로 고정된 프리픽스에 두고 종목별 가변부를 뒤에 붙인다.

**뉴스 소스는 시장별로 분리.** 영어권 벤더는 한국 기사를 제대로 못 다룬다.
US는 Finnhub `company-news`(분당 60콜), KR은 네이버 검색 API.

선택 기준은 품질이 아니라 **한도**였다. 과거 뉴스 아카이브를 살 수 없어 매일 수집해 쌓는 것이
전제이고, 수집이 한도에 막히면 그날 구멍이 생기는데 그 구멍은 나중에 메울 수 없다.

**기각: Alpha Vantage를 뉴스 메인으로.** 무료 일 25회로는 유니버스 전체 수집이 불가능하다.
대신 사전 계산된 종목별 sentiment·relevance를 **LLM 센티먼트 에이전트와 겨룰 제3자 기준선**으로
쓴다(FinRL을 비LLM 베이스라인으로 둔 것과 같은 논리). 상위 후보 종목에만 호출.

**기각: Alpha Vantage 펀더멘털.** `OVERVIEW`·`INCOME_STATEMENT`는 현재 스냅샷만 준다.
"2025-08-12에 알 수 있었던 PER"을 되돌려 받을 수 없어 데이터 레이어에서 룩어헤드가 샌다.
재무는 EDGAR `filed` 기준을 유지한다.

**기각(보류): Marketaux.** 30개 언어에 일 100회라 US/KR 통합 후보였으나 한국 언론 커버리지를
문서로 확인할 수 없었다. 샘플링 후 재검토.

## 문제와 원인

**`.gitignore`가 동작하지 않고 있었다.** 파일명이 `gitignore`로 점이 빠져 있었다.
무시 규칙이 전혀 적용되지 않는 상태여서 `.env`를 만들었다면 그대로 커밋될 수 있었다.
`env.example`도 같은 문제라 README의 `cp .env.example .env` 안내가 동작하지 않았다.
`.DS_Store`는 이미 추적되고 있었다.

**문서와 실제 구조가 어긋나 있었다.** README와 CLAUDE.md가 `src/` 레이아웃과 `docs/plan.md`를
참조하는데 파일들은 루트에 평평하게 있었고 `docs/`는 존재하지 않았다.

**git이 인덱스 잠금을 못 지웠다.** 연결된 폴더에서 파일 삭제가 기본 차단이라
`.git/index.lock`이 남아 모든 git 명령이 실패했다. 폴더 삭제 권한을 받아 해결.

**DeepSeek가 학습 컷오프를 공시하지 않는다.** 기획서의 "모델 컷오프 이후 구간만 평가" 규칙을
문자 그대로 적용할 수 없다.

## 해결

- `604a1b6` 파일명 오타 수정, `.DS_Store` 추적 해제, `src/` 레이아웃으로 이동,
  `docs/plan.md` 생성, LLM 추상화 레이어(`src/llm/`) 추가
- `c0dd076` 뉴스 소스 시장별 확정, `docs/data-sources.md` 신설,
  `published_at`/`collected_at` 이중 저장 규칙 명문화
- `65a47f3` SEC EDGAR 어댑터, 데이터 소스 상수 `config` 일원화
- `93ed712` API 인증 스모크 테스트 스크립트

컷오프 문제는 **보수적 대리 기준**으로 우회했다. V4 프리뷰 공개일(2026-04-24) 이후 구간만
백테스트 대상으로 삼고, 종목명·날짜 마스킹 테스트 비중을 올린다. 결과적으로 "전진 기록이
주 평가"라는 기존 결론이 더 강해졌다 — 백테스트는 프레임워크 비교용이지 성능 주장용이 아니다.
