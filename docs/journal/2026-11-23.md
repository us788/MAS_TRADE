# 2026-11-23

## 노이즈 바닥을 쟀다 — 두 달째 미결 1순위였던 측정

`docs/validation.md` 5.1절. 같은 구성을 여러 번 돌려 **순수 잡음 수준**을 먼저 재는
일이다. 11-22에 트랙 분리(`--kind`)를 넣어 길이 열렸고 오늘 돌렸다.

```
as_of  2026-11-18T07:00:00+09:00   ·   같은 구성 4회 (noise-1/2/3 + baseline)
90/90 성공 · $0.60 · 시장당 10~12분
```

**전제를 먼저 확인했다.** 10초 간격으로 컨텍스트를 두 번 조립해 뉴스 건수와 가변부
자수가 바이트 단위로 같은 것을 봤다 — `known_at <= as_of` 필터 덕에 그 뒤 수집된
기사가 안 섞인다. **그래서 회차 간 차이는 LLM 쪽 잡음뿐이다.**

## 결과

### 1. `temperature=0`인데 방향이 3회 중 67%만 일치한다

```
noise 3회   전원일치 20/30 (67%)   쌍 일치율 77.8%
4회 전체    전원일치 17/30 (57%)   쌍 일치율 75.6%
```

**다만 buy ↔ sell로 뒤집힌 종목은 0건이다.** 갈리는 것은 전부 `hold`와의 경계다 —
모델이 애매한 종목을 매번 다르게 반올림한다.

```
삼성전자    보유 0.34 / 매도 0.56 / 매도 0.60 / 보유 0.52     σ=0.114
한국전력    보유 0.42 / 매도 0.55 / 보유 0.40 / 보유 0.45     σ=0.066
Caterpillar 매도 0.56 / 보유 0.40 / 매도 0.57 / 보유 0.50     σ=0.078
```

### 2. 확신도 잡음이 신호의 절반이다

```
회차 간(같은 종목) 표준편차   평균 0.0428 · 최대 0.1143
회차 내(종목 간) 표준편차     평균 0.0819
                              → 잡음/신호 = 0.52
```

**미결 5번("확신도 폭이 좁다")의 정체가 이것이었다.** 폭이 좁은 게 문제가 아니라
**그 좁은 폭의 절반이 재실행 잡음**이다. 확신도 상관이 계속 0 근처였던 것도
설명된다 — 상관을 재는 변수의 절반이 잡음이면 상관은 희석된다.

표를 보면 더 분명하다. 방향이 네 번 다 같아도 확신도는 흔들린다.

```
Alphabet    매도 0.55 / 0.60 / 0.38 / 0.60     σ=0.094   (방향은 4회 일치)
SK하이닉스   매도 0.60 / 0.62 / 0.58 / 0.47     σ=0.016
SK텔레콤     매수 0.62 / 0.62 / 0.62 / 0.60     σ=0.000
```

**방향 일치율 67%는 오히려 낙관적인 수치다.**

### 3. 적중률의 분모가 회차마다 바뀐다

```
회차별 비(非)hold          17 ~ 22건 (표준편차 1.8)
분모 포함 여부가 뒤집히는 종목   13/30 (43%)
```

hold는 적중 판정에서 빠지므로 **같은 구성을 다시 돌리면 채점 대상 자체가 달라진다.**

## 그래서 A/B의 바닥이 이만큼 높다

멀티 에이전트가 단일 호출을 이겼다고 말하려면 **방향 23% 불일치 · 확신도 잡음 0.043 ·
분모 ±1.8건**을 넘는 차이를 보여야 한다. 주 30건 표본에서 그보다 작은 차이는 전부 운이다.

기획서 6절의 **"3회 이상 반복해 평균이 아니라 분산까지 본다"**가 왜 있는지가 숫자로
확인됐다. 그리고 이걸 모른 채 프롬프트를 고쳤으면 **잡음을 실력으로 읽었을 것이다** —
09-28에 적중률 0.444를 보고 고치려던 것이 정확히 그 함정이었다.

## 관찰 — 분산 자체가 신호일 수 있다

σ가 종목마다 뚜렷이 갈린다(SK텔레콤 0.000 ↔ 삼성전자 0.114). 무작위 잡음이면 이렇게
갈리지 않는다. **모델이 "확신하는 종목"과 "애매한 종목"을 구분은 하고 있는데,
그걸 확신도 숫자로 못 내보내고 있다**는 뜻으로 읽힌다.

→ **재실행 분산을 확신도 대리치로 쓰는 길**이 있다. 다만 회차를 N번 돌려야 나오므로
비용이 N배다. 지금 단계에서 할 일은 아니고 기록해 둔다.

## 미결

- **적중률의 회차 간 분산은 아직 못 쟀다.** as_of가 11-18이라 5거래일이 11-24에 찬다.
  그게 `Var(A−B)`의 직접적인 바닥이라 이틀 뒤에 한 번 더 봐야 측정이 끝난다
- **확신도를 고치는 일의 성격이 바뀌었다** (미결 5번). "폭을 넓힌다"가 아니라
  **"재실행에 안정적인 값을 내게 한다"**가 과제다. 프롬프트에서 확신도 정의를
  더 조작적으로 주는 쪽을 먼저 보는 것이 맞다
- 노이즈 측정은 `--kind noise-N`으로 언제든 다시 돌린다. 1회 $0.20, 30분
