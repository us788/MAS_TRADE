# MAS_TRADE

멀티 에이전트 LLM 주식 리서치 시스템. 미국장·한국장 각 1개 인스턴스로 운용한다.

> **실계좌 주문을 실행하지 않는다.** 시그널 기록과 가상 보유 포트폴리오 추적만 한다.
> 이 저장소의 어떤 출력도 투자 자문이 아니다.

## 목표

수익률 극대화가 아니라 **다양한 관점의 구조화된 의견 생성과 그 검증**이다.
평가 단위는 포트폴리오 수익률이 아니라 **개별 시그널**이다. 3개월간 주 1회 리밸런싱이면
판단 시점이 12번뿐이라 표본이 부족하지만, 종목 15개 × 12회 = 180건의 시그널로 쪼개면
통계적으로 말할 수 있는 것이 생긴다.

전체 설계는 [`docs/plan.md`](docs/plan.md) 참고.

## 핵심 원칙

| 원칙 | 내용 |
|---|---|
| **계산은 코드, 해석은 LLM** | PER·변동성·상관계수·샤프 등 모든 수치는 `src/compute/`의 결정론적 코드가 계산한다. LLM은 주어진 수치를 해석·비교·판단만 한다 |
| **시점 정합성** | 그 시점에 실제로 알 수 있었던 값만 쓴다. 매크로는 ALFRED vintage, 재무는 공시 제출일, 뉴스는 발행 시각 기준 |
| **리스크 엔진은 거부권을 가진다** | LLM이 제안하고 룰 엔진이 승인/기각한다 |
| **전량 로깅** | 프롬프트·응답·데이터 스냅샷을 모두 저장한다. 재현성의 전제이자 사후 ablation의 기반 |

## 구조

```
src/
├── data/      시점 정합 데이터 레이어 (US/KR 어댑터 + as-of 스냅샷)
├── compute/   결정론적 수치 계산 — LLM이 손대지 않는 영역
├── agents/    분석 에이전트, 논쟁 레이어, 리스크 엔진
└── eval/      백테스트 하네스, 시그널 채점, 지표
docs/          기획서
logs/          시그널 로그 (git 추적 제외)
data/          데이터 스냅샷 (git 추적 제외)
```

## 시작하기

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # 키를 직접 채운다
```

## 범위에서 제외

- **실계좌 주문 / 자동 매매** — 설계상 제외
- **Earnings Surprise** — 과거 시점 컨센서스 EPS는 기관용 유료 데이터라 조달 불가.
  실적 발표일 전후 주가 반응으로 대체한다
- **과거 뉴스 아카이브 백테스트** — 무료로 구할 수 없다. 지금부터 수집해 전진 검증으로만 평가
- **상장폐지 종목 포함 유니버스** — 유니버스를 시총 상위 고정 종목으로 좁혀 생존 편향을 회피
